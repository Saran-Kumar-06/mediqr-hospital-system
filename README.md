# 🏥 MediQR - Smart Hospital Management System

A full-stack web application that digitalizes hospital workflows using QR code technology. The system enables seamless interaction between patients, doctors, nurses, and pharmacists while reducing paperwork and improving efficiency.

## 🚀 Features

- 👨‍⚕️ Patient Registration
- 🔲 QR Code Generation for Patients
- 🩺 Doctor Dashboard
- 💊 Prescription Management
- 👩‍⚕️ Nurse Module
- 🏥 Pharmacy Module
- 📋 Patient Medical Records
- 🔐 Secure Login System

## 🛠 Tech Stack

### Frontend
- Angular.js
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/sarvesh57730-bot/mediqr-hospital-system.git
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm start
```
